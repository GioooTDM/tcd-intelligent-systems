## Vibe Coding vs. Agentic Coding

- **Vibe coding:** explore and create.
- **Agentic coding:** build and scale.

The problem with natural language is that it is ambiguous. Code, by contrast, is precise and unambiguous.

At the moment, we are translating natural language into code with coding agents.
