**Date:** 2026-09-14

## Lesson Summary

This lecture introduces the purpose and scope of Advanced Software Engineering, with an emphasis on applying engineering practices in team-based software development. It frames software engineering as essential for managing the complexity of large-scale systems.

- Software engineering theory, practice, and research
- GenAI tools, software architecture, Agile and eXtreme Programming (XP)
- Test-driven development, object-oriented design principles, and refactoring
- Team-based project work and the factors that influence project success or failure

## Software Engineering: Why Bother?

It is easy to:

- develop small systems or applications
- write or use GenAI-generated code for small problems
- manage communication in a one-person team
- integrate code that you write or generate with GenAI yourself
- overlook software engineering when maintenance is not required
